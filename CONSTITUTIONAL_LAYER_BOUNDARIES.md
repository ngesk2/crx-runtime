# CONSTITUTIONAL_LAYER_BOUNDARIES

## Layer 0 — Constitutional Replay Kernel
Owns:

- replay
- lineage
- witnesses
- canonicalization
- signatures
- hashes
- permissions
- invariants
- deterministic failures
- replay domains

Layer 0 is constitutional law.

Layer 0 is the source of truth.

Layer 0 is runtime-independent.

## Layer 1 — Object Protocol
Owns:

- Object schemas
- Actor schemas
- Relationship events
- Follow protocol
- Subscription protocol
- Object validation

Layer 1 may depend on Layer 0.

## Layer 2 — Runtime / Hydration
Owns:

- Web Components
- Shadow DOM
- Rendering
- Hydration
- Browser integration
- Caching

Layer 2 may depend on Layers 0–1.

## Layer 3 — Intelligence / Marketplace / Discovery
Owns:

- AI
- Recommendations
- Attribution
- Marketplace logic
- Placement matching
- Ranking
- Search
- Monetization

Layer 3 may depend on Layers 0–2.

Layer 0 may NEVER depend on Layer 3.
