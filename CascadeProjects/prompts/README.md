# Agent Prompts

This directory contains canonical prompts for agent execution.

## Prompt Principles

1. **Single Source of Truth**: Each agent type has ONE canonical prompt
2. **No Duplication**: Duplicate prompts are constitutional violations
3. **Constitutional Alignment**: All prompts must reference constitutional principles
4. **Policy Awareness**: Prompts must include policy evaluation requirements
5. **Lineage Preservation**: Prompts must instruct agents to preserve lineage

## Prompt Categories

### Constitutional Prompts
- Audit agent prompts
- Policy evaluation agent prompts
- Replay validation agent prompts
- Constitutional repair agent prompts

### Runtime Prompts
- Refactor agent prompts
- Schema generation agent prompts
- Test generation agent prompts
- Repo indexing agent prompts

### Domain Prompts
- Education-specific agent prompts
- Pedagogical agent prompts
- Assessment agent prompts

## Prompt Structure

All agent prompts must include:
1. Constitutional context
2. Policy constraints
3. Lineage requirements
4. Audit requirements
5. Task-specific instructions

## Prompt Evolution

When evolving prompts:
1. Create new version
2. Maintain constitutional alignment
3. Update policy references
4. Test against constitutional invariants
5. Document changes
