## CONSTITUTIONAL PRINCIPLES

### 1. Truth ≠ Embedding
**Principle:** Events are truth. Embeddings are projections.

**Architecture:**
- Events persist in PostgreSQL (truth)
- Embeddings generated by Ollama (projection)
- Embeddings stored in Qdrant (storage)
- If Ollama dies, events still persist
- If Qdrant dies, events can be reprojected

### 2. Authority is Explicit
**Principle:** All claims have provenance.

**Authority Chain:**
```
Vault (Human-Readable Authority)
  ↓
Qdrant (Vector Projection)
  ↓
Mission Control (Observability)
  ↓
MCP (Tool Access)
  ↓
Open WebUI (Operator Interface)
  ↓
Ollama (Computation)
```

### 3. State is Replayable
**Principle:** All state can be reconstructed from events.

**Replay Engine:**
- Deterministic event processing
- Canonical event envelopes
- Merkle tree verification
- Invariant checking

### 4. Knowledge Survives Component Failure
**Principle:** No single component failure destroys knowledge.

**Survivability:**
- PostgreSQL: Canonical event persistence
- Qdrant: Vector projection (rebuildable)
- Vault: Human-readable authority
- Google Drive: Backup layer

### 5. Embeddings are Disposable
**Principle:** Embeddings can be regenerated from truth.

**Projection:**
- Vault → Projection Worker → Ollama → Qdrant
- Delete Qdrant collection
- Re-run projection worker
- Identical projection verified

### 6. Truth is Reconstructable
**Principle:** Truth can be reconstructed from any projection.

**Verification:**
- Vault hash → Qdrant hash
- Delete → Rebuild → Compare
- Hash match = Projection Certified
