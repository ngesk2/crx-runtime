## Question 1: What is truth?

### Distinguish Required

We must formally distinguish between:

- **Observed Truth**
- **Claimed Truth**
- **Derived Truth**
- **Governance Truth**

### Current Understanding

**Observed Truth**
- Events directly witnessed
- Raw input from reality
- Unprocessed observations
- Example: RSS feed received, email received

**Claimed Truth**
- Assertions made by actors
- Statements without verification
- Claims requiring evidence
- Example: "Alice follows Bob"

**Derived Truth**
- Truth computed from other truths
- Replay-reconstructed state
- Inferred relationships
- Example: "Alice follows Bob" derived from FOLLOW_CREATED event

**Governance Truth**
- Truth established by authority
- Policy decisions
- Constitutional amendments
- Example: "Article 42 is revoked"

### Unresolved Constitutional Question

**How do we handle contradictory truths?**

Example:
- Event A: "Alice follows Bob"
- Event B: "Alice unfollows Bob"
- Event C: "Alice follows Bob again"

Which is truth?

**Current Position:**
- All events are truth
- Truth is temporal
- Current state is derived from latest events
- History preserves all truth

**Future Constitutional Scholarship Required:**
- Formal truth reconciliation law
- Truth conflict resolution mechanisms
- Truth hierarchy definitions
