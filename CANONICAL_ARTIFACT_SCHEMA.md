# Canonical Artifact Schema

**Audit Date:** 2026-06-24
**Audit Type:** PHASE E.7B - Investigation 2
**Objective:** Design minimum artifact schema to unify all runtime objects

---

# Executive Summary

**Canonical Artifact Schema:** Single unified schema for all runtime objects (documents, events, claims, observations, projections, repositories, code symbols).

**Design Principle:** Minimum viable schema that enables:
1. PostgreSQL storage
2. Qdrant indexing
3. Ollama reasoning
4. Witness verification
5. Authority ranking

---

# Canonical Artifact Schema

## Core Schema

```json
{
  "artifact_id": "string (UUIDv4 or SHA256)",
  "artifact_type": "string (enum)",
  "authority_class": "string (enum)",
  "verification_status": "string (enum)",
  "lineage_root": "string (artifact_id or null)",
  "witness_root": "string (SHA256 or null)",
  "created_from": "string (artifact_id or null)",
  "superseded_by": "string (artifact_id or null)",
  "content_hash": "string (SHA256)",
  "event_hash": "string (SHA256)",
  "created_at": "ISO8601 timestamp",
  "updated_at": "ISO8601 timestamp",
  "content": "object (variable)",
  "metadata": "object (variable)"
}
```

# Field Classification

## Mandatory Fields

### artifact_id
- **Type:** string (UUIDv4 or SHA256)
- **Purpose:** Unique artifact identifier
- **Constitutional Law:** IDENTITY_LAW
- **Source:** Generated by system
- **Unification:** All current objects have unique identifiers (document paths, event IDs, artifact IDs)
- **Classification:** MANDATORY

### artifact_type
- **Type:** string (enum)
- **Purpose:** Artifact type classification
- **Constitutional Law:** AUTHORITY_LAW
- **Source:** System classification
- **Unification:** Unifies 18 current artifact types into canonical types
- **Classification:** MANDATORY

### authority_class
- **Type:** string (enum)
- **Purpose:** Authority class hierarchy
- **Constitutional Law:** AUTHORITY_LAW
- **Source:** authority_objects.category or derived
- **Unification:** Replaces current authority_level, category fields
- **Classification:** MANDATORY

### content_hash
- **Type:** string (SHA256)
- **Purpose:** Content integrity verification
- **Constitutional Law:** VERIFICATION
- **Source:** Computed from content
- **Unification:** Replaces payload_hash, sha256 fields
- **Classification:** MANDATORY

### created_at
- **Type:** ISO8601 timestamp
- **Purpose:** Creation timestamp
- **Constitutional Law:** EVENT_LAW
- **Source:** System timestamp
- **Unification:** All current objects have timestamps
- **Classification:** MANDATORY

---

## Optional Fields

### verification_status
- **Type:** string (enum)
- **Purpose:** Verification status
- **Constitutional Law:** VERIFICATION
- **Source:** authority_objects.status or derived
- **Unification:** Replaces current status fields
- **Classification:** OPTIONAL (null for unverified artifacts)

### lineage_root
- **Type:** string (artifact_id or null)
- **Purpose:** Lineage root identifier
- **Constitutional Law:** LINEAGE
- **Source:** authority_lineage.ancestor or derived
- **Unification:** Replaces current lineage fields
- **Classification:** OPTIONAL (null for root artifacts)

### witness_root
- **Type:** string (SHA256 or null)
- **Purpose:** Witness root identifier
- **Constitutional Law:** WITNESS_LAW
- **Source:** authority_witness.witness_root
- **Unification:** Replaces current witness fields
- **Classification:** OPTIONAL (null for unwitnessed artifacts)

### created_from
- **Type:** string (artifact_id or null)
- **Purpose:** Parent artifact identifier
- **Constitutional Law:** LINEAGE
- **Source:** Event sourcing or derived
- **Unification:** Replaces current parent/ancestor fields
- **Classification:** OPTIONAL (null for root artifacts)

### superseded_by
- **Type:** string (artifact_id or null)
- **Purpose:** Superseding artifact identifier
- **Constitutional Law:** AUTHORITY_LAW
- **Source:** authority_supersession.superseded_by
- **Unification:** Replaces current supersession fields
- **Classification:** OPTIONAL (null for current artifacts)

### event_hash
- **Type:** string (SHA256)
- **Purpose:** Event hash for replay verification
- **Constitutional Law:** REPLAY_LAW
- **Source:** Event payload hash
- **Unification:** Replaces current event_hash fields
- **Classification:** OPTIONAL (null for non-event artifacts)

### updated_at
- **Type:** ISO8601 timestamp
- **Purpose:** Last update timestamp
- **Constitutional Law:** EVENT_LAW
- **Source:** System timestamp
- **Unification:** Replaces current updated_at fields
- **Classification:** OPTIONAL (null for immutable artifacts)

---

## Variable Fields

### content
- **Type:** object (variable)
- **Purpose:** Artifact-specific content
- **Constitutional Law:** None (content varies by type)
- **Source:** Artifact-specific
- **Unification:** Unifies all current content fields (document text, event payload, claim data, etc.)
- **Classification:** VARIABLE (schema varies by artifact_type)

### metadata
- **Type:** object (variable)
- **Purpose:** Artifact-specific metadata
- **Constitutional Law:** None (metadata varies by type)
- **Source:** Artifact-specific
- **Unification:** Unifies all current metadata fields
- **Classification:** VARIABLE (schema varies by artifact_type)

# Schema Validation

## PostgreSQL Storage

**Table Schema:**
```sql
CREATE TABLE artifacts (
  artifact_id VARCHAR(255) PRIMARY KEY,
  artifact_type VARCHAR(50) NOT NULL,
  authority_class VARCHAR(50) NOT NULL,
  verification_status VARCHAR(50),
  lineage_root VARCHAR(255),
  witness_root VARCHAR(255),
  created_from VARCHAR(255),
  superseded_by VARCHAR(255),
  content_hash VARCHAR(64) NOT NULL,
  event_hash VARCHAR(64),
  created_at TIMESTAMP NOT NULL,
  updated_at TIMESTAMP,
  content JSONB NOT NULL,
  metadata JSONB
);

CREATE INDEX idx_artifacts_type ON artifacts(artifact_type);
CREATE INDEX idx_artifacts_authority ON artifacts(authority_class);
CREATE INDEX idx_artifacts_lineage ON artifacts(lineage_root);
CREATE INDEX idx_artifacts_witness ON artifacts(witness_root);
CREATE INDEX idx_artifacts_content_hash ON artifacts(content_hash);
```

**Feasibility:** HIGH - PostgreSQL supports JSONB for variable content/metadata
