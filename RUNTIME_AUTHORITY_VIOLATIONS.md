# Runtime Authority Violations Audit

**Date:** 2026-06-24
**Audit Type:** Runtime code that defines constitutional authority
**Constitutional Law:** TRUTH_LAW.md (truth = event), AUTHORITY_TAXONOMY_SPEC.md (authority = spec)
**Principle:** Runtime may consume law. Runtime may never define law.

---

## Summary

**6 files** contain hardcoded authority definitions. These are constitutional violations.

The correct architecture:

```
AUTHORITY_TAXONOMY_SPEC.md
    ↓
Constitutional Compiler (CONSTITUTION_COMPILER_SPEC.md)
    ↓
authority_registry.json
    ↓
Runtime consumes registry (read-only)
```

---

## Violation 1 (PRIMARY) — `runtime/tools/authority_search.py`

### Location

**File:** `runtime/tools/authority_search.py`
**Lines:** 25-62

### Violation

Hardcoded authority class hierarchy and mapping function. Python is defining constitutional law.

### Evidence

```python
# Line 26-37: Authority class hierarchy hardcoded in Python
AUTHORITY_CLASSES = [
    "CONSTITUTIONAL_LAW",
    "CANONICAL_SPEC",
    "CREATOR_RESEARCH",
    "CREATOR_NOTES",
    "IMPORTED_DOCUMENT",
    "REPOSITORY_DOCUMENTATION",
    "SCRIPT",
    "SUMMARY",
    "AI_GENERATED_ANALYSIS",
    "TEMPORARY_OBSERVATION"
]

# Line 39: Class order computed from hardcoded list
AUTHORITY_CLASS_ORDER = {cls: idx for idx, cls in enumerate(AUTHORITY_CLASSES)}

# Line 42-62: Category-to-class mapping hardcoded in Python
def resolve_authority_class(category: str) -> str:
    mapping = {
        'constitutional law': 'CONSTITUTIONAL_LAW',
        'constitutional': 'CONSTITUTIONAL_LAW',
        ...
    }
    return mapping.get(category.lower(), 'TEMPORARY_OBSERVATION')
```

### Severity

**CRITICAL** — Defines the entire authority class hierarchy in runtime code.

### Required Fix

- Remove `AUTHORITY_CLASSES` list — load from registry
- Remove `resolve_authority_class()` — consume from registry
- `authority_search.py` may only CONSUME the registry, never define it

## Violation 4 — `runtime/projection_worker/constitutional_projection_worker.py`

### Location

**File:** `runtime/projection_worker/constitutional_projection_worker.py`
**Lines:** 96-111

### Violation

File-path-based authority level determination hardcoded in Python.

### Evidence

```python
def determine_authority_level(self, file_path: str) -> str:
    """Determine authority level based on file path."""
    if 'constitutional/immutable' in file_path:
        return 'constitutional'
    elif 'laws' in file_path:
        return 'constitutional'
    elif 'constitution' in file_path:
        return 'constitutional'
    elif 'audits' in file_path:
        return 'operational'
    elif 'capabilities' in file_path:
        return 'operational'
    elif 'runbooks' in file_path:
        return 'operational'
    else:
        return 'working'
```

### Severity

**HIGH** — Creates a SECOND, competing authority scheme (3 levels: constitutional > operational > working) that is not aligned with the declared 10-level class hierarchy.

### Required Fix

- Remove `determine_authority_level()` — authority must come from registry
- File path must NOT determine constitutional authority
- This function creates the "3 competing schemes" problem documented in CONSTITUTIONAL_REPOSITORY_AUDIT.md
