## CONSTITUTIONAL VIOLATION

**CRX Applications do NOT delegate authority to PING:**
- Events created by CRX Application (brain/src/constitutional/event_emitter.py)
- IDs generated by CRX Application (SQLite auto-increment)
- Payloads NOT canonicalized (raw data stored directly)
- Lineage NOT tracked (no lineage columns)

**PING Gateway does NOT delegate authority to PING runtime:**
- Events created by PING Gateway (not PING runtime)
- IDs generated by PING Gateway (crypto module, not PING CanonicalHashAuthority)
- Payloads NOT canonicalized (JSON.stringify, not PING CanonicalJson)
- Lineage NOT tracked (no lineage tracking)

**PING Commit Service DOES delegate authority to PING:**
- Events created by PING Runtime (PING Commit Service)
- IDs generated by PING Runtime (PING CanonicalHashAuthority)
- Payloads canonicalized by PING Runtime (PING CanonicalJson)
- Lineage tracked by PING Runtime (PING LineageGraph)
