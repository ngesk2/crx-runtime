# Tier 6 — Industry Packs Specification

## Overview

Sell operating systems for specific industries rather than generic software. Each industry pack ships with workflows, automations, KPIs, dashboards, marketing, and templates—all built on the same constitutional kernel.

## Industry Pack Concept

**Same Kernel. Different Projections.**

Each industry pack is a configuration layer on top of the constitutional runtime:
- **Constitutional Kernel**: Events, missions, workers, knowledge graph, replay (unchanged)
- **Industry Pack**: Industry-specific projections, workflows, KPIs, automations, templates

## Industry Pack Structure

### Configuration File

```yaml
industry_pack:
  name: "Roofing OS"
  version: "1.0.0"
  target_industry: "roofing"
  
workflows:
  - name: "roof_replacement"
    steps:
      - event: "LEAD_CREATED"
        next: "ROOF_INSPECTION"
      - event: "ROOF_INSPECTION"
        next: "MATERIAL_MEASUREMENT"
      - event: "MATERIAL_MEASUREMENT"
        next: "ESTIMATE_GENERATION"
      - event: "ESTIMATE_GENERATED"
        next: "CUSTOMER_APPROVAL"
      - event: "CUSTOMER_APPROVED"
        next: "MATERIAL_ORDERING"
      - event: "MATERIAL_ORDERED"
        next: "SCHEDULING"
      - event: "SCHEDULED"
        next: "INSTALLATION"
      - event: "INSTALLATION_COMPLETED"
        next: "FINAL_INSPECTION"
      - event: "FINAL_INSPECTION_PASSED"
        next: "PAYMENT_COLLECTION"
      - event: "PAYMENT_COLLECTED"
        next: "REVIEW_REQUEST"

kpis:
  - name: "jobs_completed_per_week"
    source: "JOB_COMPLETED"
    calculation: "count(events) where week = current_week"
    target: 10
  
  - name: "average_job_duration"
    source: "JOB_COMPLETED"
    calculation: "avg(duration) where week = current_week"
    target: "3 days"
  
  - name: "customer_satisfaction"
    source: "REVIEW_RECEIVED"
    calculation: "avg(rating) where week = current_week"
    target: 4.5

dashboards:
  - name: "job_pipeline"
    widgets:
      - type: "pipeline"
        stages: ["inspection", "measurement", "estimate", "approved", "scheduled", "installation", "completed"]
  
  - name: "crew_scheduling"
    widgets:
      - type: "schedule"
        resource: "crew"
  
  - name: "material_inventory"
    widgets:
      - type: "inventory"
        resource: "material"

automations:
  - name: "weather_delay_notification"
    trigger: "WEATHER_ALERT"
    steps:
      - worker: "notification_sender"
        capability: "sms"
  
  - name: "material_reorder_alert"
    trigger: "MATERIAL_LOW"
    steps:
      - worker: "order_creator"
        capability: "postgres"

templates:
  - name: "roof_inspection_checklist"
    type: "form"
    fields:
      - name: "roof_type"
        type: "select"
        options: ["shingle", "metal", "tile", "flat"]
      - name: "roof_age"
        type: "number"
      - name: "damage_assessment"
        type: "text"
  
  - name: "estimate_template"
    type: "document"
    template: "estimate_roofing.html"

marketing:
  - name: "before_after_campaign"
    trigger: "JOB_COMPLETED"
    content:
      - type: "social_post"
        platform: "facebook"
      - type: "social_post"
        platform: "instagram"
  
  - name: "seasonal_promotion"
    trigger: "SEASON_START"
    content:
      - type: "email_campaign"
        template: "seasonal_promotion.html"
```

## API Endpoints Required

### Industry Pack Management

```
GET /api/industry-packs
Response: { packs: [{ id, name, version, target_industry }] }

POST /api/industry-packs/install
Request: { pack_id, configuration }
Response: { installed: true, pack_id }

GET /api/industry-packs/installed
Response: { packs: [{ pack_id, name, configuration, status }] }

PUT /api/industry-packs/installed/{pack_id}/configure
Request: { configuration }
Response: { updated: true }

DELETE /api/industry-packs/installed/{pack_id}
Response: { uninstalled: true }
```

### Industry Pack Features

```
GET /api/industry-packs/{pack_id}/workflows
Response: { workflows: [{ name, steps, events }] }

GET /api/industry-packs/{pack_id}/kpis
Response: { kpis: [{ name, calculation, target, current_value }] }

GET /api/industry-packs/{pack_id}/dashboards
Response: { dashboards: [{ name, widgets }] }

GET /api/industry-packs/{pack_id}/automations
Response: { automations: [{ name, trigger, steps }] }

GET /api/industry-packs/{pack_id}/templates
Response: { templates: [{ name, type, fields }] }
```

## Constitutional Events

### Industry Pack Events

```
INDUSTRY_PACK_INSTALLED
- payload: { pack_id, name, version, installed_at }
- projection: Industry pack status projection

INDUSTRY_PACK_CONFIGURED
- payload: { pack_id, configuration, configured_at }
- projection: Industry pack configuration projection

INDUSTRY_PACK_UNINSTALLED
- payload: { pack_id, uninstalled_at }
- projection: Industry pack status projection
```

## Projections Required

### IndustryPackStatusProjection
- **Source**: Industry pack events
- **Output**: Installed industry packs with status
- **Storage**: PostgreSQL
- **Update**: Real-time

### IndustryPackConfigurationProjection
- **Source**: Industry pack events
- **Output**: Industry pack configurations
- **Storage**: PostgreSQL
- **Update**: Real-time

### IndustrySpecificProjections
Each industry pack defines its own projections:
- **Roofing OS**: Job pipeline projection, material inventory projection
- **HVAC OS**: Service call queue projection, parts inventory projection
- **Plumbing OS**: Emergency call queue projection, parts inventory projection

## Workers Required

### IndustryPackInstaller
- **Capability**: PostgreSQL
- **Input**: Industry pack configuration
- **Output**: Installed industry pack
- **Events**: `INDUSTRY_PACK_INSTALLED`

### IndustryPackConfigurator
- **Capability**: PostgreSQL
- **Input**: Industry pack configuration changes
- **Output**: Updated configuration
- **Events**: `INDUSTRY_PACK_CONFIGURED`

### IndustrySpecificWorkers
Each industry pack defines its own workers:
- **Roofing OS**: Weather monitor, material tracker, permit checker
- **HVAC OS**: Seasonal scheduler, parts tracker, maintenance scheduler
- **Plumbing OS**: Emergency router, parts tracker, maintenance scheduler

## Notes

- Industry packs are configuration layers, not code changes
- All industry-specific actions create constitutional events
- Industry packs share the same constitutional kernel
- Industry packs can be customized per business
- Industry packs can be cloned and modified
- Industry packs include marketing templates
- Industry packs are versioned for updates
- Industry packs can be community-contributed
